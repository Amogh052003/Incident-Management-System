# Audit API

The Audit API provides endpoints for recording and retrieving
audit events generated by the Incident Management System.

## POST /audit/log

**Documentation ID:** `audit.createLog`

Records an event in the audit log.

### Request Body

| Field | Type | Required | Description |
|---|---|---|---|
| `event_type` | `string` | Yes | - Type of event being recorded. |
| `component` | `string` | No | - Component associated with the event. |
| `severity` | `string` | No | - Severity of the event. |
| `message` | `string` | No | - Human-readable description of the event. |
| `metadata` | `object` | No | - Additional structured metadata. |

### Responses

| Status | Description |
|---|---|
| `201` | - Audit event successfully logged. |
| `400` | - event_type was not provided. |
| `500` | - Failed to create the audit event. |

## GET /audit/logs

**Documentation ID:** `null`

Retrieves audit events with optional filtering and pagination.

### Query Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `event_type` | `string` | No | Filter by event type. |
| `component` | `string` | No | Filter by component. |
| `severity` | `string` | No | Filter by severity. |
| `limit` | `integer` | No | Maximum number of records to return. Defaults to 100. |
| `offset` | `integer` | No | Number of records to skip. Defaults to 0. |

### Responses

| Status | Description |
|---|---|
| `200` | - List of audit log records. |
| `500` | - Failed to retrieve audit logs. |

## GET /audit/filters

**Documentation ID:** `null`

Returns the distinct components and severities present in the audit log.

### Responses

| Status | Description |
|---|---|
| `200` | - Available components and severities. |
| `500` | - Failed to retrieve audit filters. |
